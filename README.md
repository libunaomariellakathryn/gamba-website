# gamba-website
Current working website of the store, Gamba!

## Pages
- index.html (home)
- contact-us.html
- privacy-policy.html
- terms-and-conditions.html
- dont-be-late-tee.html
- everyday-comfort-tee.html
- do-good-work-tee.html

## Assets
- css/style.css: custom styling, loaded after Bootstrap
- js/script.js: product search filtering and demo form confirmations
- images/: shirt mockups for the hero and three product images

## Notes
- Newsletter form show local confirmation messages only. They are not connected to a backend and do not transmit/store data.
- Contact details and social links are sample destinations only.
- Bootstrap 5.3.3 CSS and JavaScript are loaded from jsDelivr CDN. Google Fonts are loaded from Google Fonts.
